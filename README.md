# Micro Rally

A cozy, flat-shaded low-poly rally game for the browser. Drive procedural
point-to-point stages, earn prize money, upgrade your car. Everything —
terrain, cars, sounds — is generated procedurally.

```sh
pnpm install
pnpm dev          # http://localhost:3000
pnpm check        # typecheck + lint + unit tests + build
pnpm test:e2e     # Playwright smoke tests
```

See [CLAUDE.md](CLAUDE.md) for project rules and [docs/](docs/) for the
brief, plan, architecture and decisions.
